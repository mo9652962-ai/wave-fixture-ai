# 治具设计规则 Profiles（Rule Profiles）

本目录把三套厂商/行业来源的波峰焊治具设计规则并列落盘为可机读数据
（[`profiles.json`](profiles.json)），核对日期 2026-11-16，每套 profile 都带出处链接。

## 使用纪律

- **三套口径不可混用。** Kaisertech（英制）、MB Manufacturing（英制）与国内通用规范
  （公制）是不同材料/厂商体系下的数值；同一块治具只按一套 profile 校验。
- **数值是转录值，不是普世标准。** 采用前请打开出处原文复核上下文
  （适用材料、板厚前提、无铅/有铅工艺差异）。
- **当前状态**：`drc.py` 尚未消费这些 profile。本目录是规则 profile 化
  （极限/推荐两档 + 每条规则带可机读出处）的第一步数据落盘；
  接入时应保持现有默认行为不变，profile 只做显式选择。

## 三套 profile 速览

| profile | 单位 | 代表数值 |
|---|---|---|
| kaisertech | inch | 板槽放大 0.030″、密封墙最薄 0.030″、底面倒角 60°、无铅 PTH 间隙 ≥0.100″ |
| mb-manufacturing | inch | 唇厚 0.080″±0.010″、壁厚 ≥0.040″、地板厚 ≥0.100″ |
| cn-general | mm | 板间隙 0.5、板下沉 1.5、倒角 25°±5°、余厚 ≥0.8、压扣约 8 cm 一个、常规板厚 6 |

另注：合成石成不了的薄密封墙可用钛合金嵌件做到约 0.4 mm（见 profiles.json 的 notes）。
